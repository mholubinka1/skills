# AI agent documentation lives in .agent-docs/, not agent-docs/

The `agent-docs/` directory appeared as a first-class source directory alongside `src/`, `lib/`, and similar code directories in file browsers and `ls` output, creating visual noise that misrepresented its role as tooling scaffolding rather than application code. We decided to rename it to `.agent-docs/`, following the established hidden-directory convention used by `.github/`, `.husky/`, and `.vscode/`. The visible `agent-docs/` name was the genuine alternative and was rejected because hiding the directory keeps AI agent documentation accessible to tools that know to look for it while removing it from casual browsing. The `init-agent-docs` skill migrates existing `agent-docs/` layouts automatically on first run after upgrade.
